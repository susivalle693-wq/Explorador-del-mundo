# Explorador-del-mundo
Explora 250 países previamente disponibles


## ⚠️ Nota

Esta app consume la API pública y gratuita de [REST Countries](https://restcountries.com/) para obtener la información de los países. Al ser un servicio gratuito con mucho tráfico, en ocasiones puede responder con errores temporales o demorar en cargar. Si al abrir la página ve el mensaje "Algo salió mal", esperá unos segundos y dale click en "Reintentar" — el problema es del servicio externo, no de la aplicación.
